# Customer Feedback Analysis (Amazon)
Dataset: 256,000+ customer reviews for an Amazon best-selling product.
Tools: Python (pandas, matplotlib)

Key Findings:

- Overall satisfaction is extremely high, with an average rating of 4.64 / 5.0.
- 75% of all reviews are perfect 5-star ratings.
- Identified 6,408 low-rated reviews (1-2 stars) that represent a 2.5% segment of the feedback.

Next Steps: Conduct Natural Language Processing (NLP) text analysis on the 6,408 low-rated reviews to identify common complaint themes (e.g., durability, leaking, shipping).

Dataset Source: [Link to the Amazon Reviews Dataset on Hugging Face](https://huggingface.co/datasets/Aryan1780/Amazon-Reviews-Dataset/blob/main/reviews.csv).
